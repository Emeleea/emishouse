About

Hello! My name is Emi! (she/her/hers)
Emi's House is a website established by myself and Erin (she/her/hers). It is meant to be a side-project amidst my Community Worker journey. This website aims to be a few different things:

1. A journal on what I've learned amidst my trans experience

2. An up to date, helpful, and streamlined resource for those newly transitioning in the province.

Layout heavily inspired by the Melee Library website.
